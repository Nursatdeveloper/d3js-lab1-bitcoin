# Лабораторная работа №1 — Визуализация данных с использованием D3.js

Веб-страница загружает CSV-файл с метриками сети **Bitcoin** и строит по нему два
интерактивных графика с помощью библиотеки [D3.js](https://d3js.org/) v7.

## Набор данных

`data/bitcoin_monthly.csv` — среднемесячные показатели блокчейна Bitcoin
с января 2019 по октябрь 2026 года (**94 записи, 6 столбцов**).
Источник — открытый [Charts API blockchain.com](https://www.blockchain.com/explorer/charts).

| Столбец | Тип | Описание |
|---|---|---|
| `month` | дата (`ГГГГ-ММ`) | месяц |
| `price_usd` | число | средняя рыночная цена 1 BTC, USD |
| `transactions_per_day` | число | подтверждённых транзакций в сутки |
| `hash_rate_ehs` | число | хешрейт сети, EH/s (10¹⁸ хешей в секунду) |
| `avg_block_size_mb` | число | средний размер блока, МБ |
| `fees_usd_per_day` | число | сумма комиссий майнерам в сутки, USD |

Скрипт `tools/build_csv.py` воспроизводит файл: скачивает дневные ряды из API
и усредняет их по месяцам (`python tools/build_csv.py`).

## Запуск

Браузер не разрешает `d3.csv()` читать файл, если страница открыта двойным
щелчком (`file://`), поэтому нужен любой локальный HTTP-сервер.
Из папки `d3-lab1` выполните одну из команд:

```bash
python -m http.server 8000
```

```bash
npx serve .
```

и откройте <http://localhost:8000> (для `npx serve` — адрес, который он выведет).
Также подойдёт расширение **Live Server** в VS Code: правый клик по `index.html` → *Open with Live Server*.

Нужен доступ в интернет: D3.js подключается с CDN `cdnjs.cloudflare.com`.

## Что делает страница

1. **Загрузка CSV** — `d3.csv("data/bitcoin_monthly.csv", convertRow)` возвращает Promise.
   Ошибки (файл не найден, страница открыта через `file://`, нет корректных строк)
   перехватываются в `.catch()` и выводятся на странице красным блоком.
2. **Обработка данных** — функция `convertRow` вызывается для каждой строки:
   числовые столбцы приводятся из строки к числу унарным `+`, месяц разбирается
   `d3.timeParse("%Y-%m")` в объект `Date`. Строки с `NaN` отбрасываются.
   На странице выводятся количество записей, количество и названия столбцов
   (с типом после преобразования), период и первые 10 строк таблицей.
3. **Визуализация 1 — столбчатая диаграмма.** Месяцы группируются по годам
   (`d3.rollups` + `d3.mean`), каждый столбец — среднее значение выбранного
   показателя за год. Шкалы: `d3.scaleBand` (годы) и `d3.scaleLinear` (значения).
4. **Визуализация 2 — линейный график.** Помесячная динамика выбранного
   показателя (`d3.scaleTime`, `d3.line`, `d3.area`). Пунктиром отмечены
   халвинги Bitcoin (май 2020, апрель 2024).
5. **Интерактивность (дополнительное задание):**
   - всплывающие подсказки со значениями при наведении на столбцы и на линию
     (на линейном графике — перекрестие, ближайшая точка ищется `d3.bisector`);
   - выбор отображаемого показателя (цена, транзакции, хешрейт, размер блока, комиссии);
   - фильтрация данных по диапазону лет.

   При любом изменении оба графика перестраиваются (`renderAll()`); графики также
   перерисовываются при изменении размера окна.
